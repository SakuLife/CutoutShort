# GAS デプロイ手順

`YouTubeAuth.gs` を Google Apps Script としてデプロイし、契約者が認証できるようにする。

## 前提条件

- Google Cloud Console で OAuth クライアントが作成済み
- `YouTubeAuth.gs` の `CLIENT_ID`, `CLIENT_SECRET`, `SPREADSHEET_ID` が正しく設定済み

---

## Step 1: GAS プロジェクトを作成

1. [Google Apps Script](https://script.google.com) にアクセス
2. 「新しいプロジェクト」をクリック
3. プロジェクト名を設定（例: `YouTubeAuth`）
4. `YouTubeAuth.gs` の内容を全てコピペ

---

## Step 2: デプロイ

1. 右上の「デプロイ」→「新しいデプロイ」をクリック

2. 「種類の選択」で **ウェブアプリ** を選択

3. 設定:
   - **説明**: `YouTube認証` など
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`（重要！）

4. 「デプロイ」をクリック

5. **デプロイURL** をコピー
   ```
   https://script.google.com/macros/s/XXXXXXXX/exec
   ```

---

## Step 3: Google Cloud Console でリダイレクトURI を設定

これが一番忘れやすい。

1. [Google Cloud Console](https://console.cloud.google.com) にアクセス

2. 対象プロジェクトを選択

3. 「APIとサービス」→「認証情報」

4. OAuth 2.0 クライアント ID をクリック（編集）

5. **承認済みのリダイレクト URI** に以下を追加:
   ```
   https://script.google.com/macros/s/XXXXXXXX/exec
   ```
   （Step 2でコピーしたURLをそのまま）

6. 「保存」

---

## Step 4: 動作確認

1. デプロイURLにブラウザでアクセス

2. 認証ページが表示される → 「Googleでログイン」をクリック

3. Googleアカウントでログイン → チャンネル選択

4. 「認証完了！」ページが表示されればOK

5. スプレッドシートの `YouTubers` シートを確認
   - 新しい行が追加されている
   - `refresh_token` が入っている

---

## よくあるエラー

### 「redirect_uri_mismatch」エラー

**原因**: Cloud Console のリダイレクトURI が一致していない

**対処**:
1. GASのデプロイURLを再確認
2. Cloud Console で完全一致するURIを追加
3. 末尾のスラッシュに注意（あり/なしで別扱い）

### 「このアプリはGoogleで確認されていません」警告

**原因**: 本番用の審査を受けていない（開発中は正常）

**対処**:
1. 「詳細」をクリック
2. 「（安全ではないページ）に移動」をクリック
3. 自分や契約者のみが使う場合は審査不要

### 「リフレッシュトークンが取得できませんでした」

**原因**: 既に認証済みのアカウントで再認証した

**対処**:
1. https://myaccount.google.com/permissions にアクセス
2. このアプリの権限を削除
3. 再度認証

### 403エラー / アクセス拒否

**原因**: デプロイ時の「アクセスできるユーザー」設定

**対処**:
1. GASエディタで「デプロイ」→「デプロイを管理」
2. 編集（鉛筆アイコン）をクリック
3. 「アクセスできるユーザー」を「全員」に変更
4. 再デプロイ

---

## デプロイURLを契約者に共有

認証ページは契約者向けにデザインされている:
- システムの説明
- 必要な権限の説明
- ログインボタン

契約者には **デプロイURLを送るだけ** でOK。
Client ID/Secret を教える必要なし。

---

## 再デプロイ時の注意

コードを修正した場合:
1. 「デプロイ」→「デプロイを管理」
2. 「編集」（鉛筆アイコン）
3. 「バージョン」を「新バージョン」に変更
4. 「デプロイ」

**URLは変わらない**（既存の契約者向けリンクはそのまま使える）
